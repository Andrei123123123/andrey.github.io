# 📸 Папка с изображениями

Здесь хранятся все картинки для сайта.
Чтобы заменить — просто положи файл с таким же именем.

## Текущие файлы:

| Файл | Размер | Описание |
|------|--------|----------|
| `hero-tenerife.jpg` | 1920×1080 | Главное фото (hero-секция) |
| `visa-support.jpg` | 640×640 | Карточка «Визовая поддержка» |
| `all-inclusive.jpg` | 640×640 | Карточка «Полный тур» |
| `community.jpg` | 640×640 | Карточка «Community» |

## Как добавить новое фото:

1. Положи файл сюда
2. В нужном компоненте добавь импорт:
   ```tsx
   import myImage from "@/assets/my-image.jpg";
   ```
3. Используй в JSX:
   ```tsx
   <img src={myImage} alt="Описание" />
   ```

> ⚠️ Используй формат `.jpg` или `.webp` для фото, `.png` для иконок с прозрачностью.
