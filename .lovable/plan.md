# Аудит сайта Tennerife Tennis Retreat

Прошёлся по коду, метаданным, HTTP-ответам и структуре лендинга. Ниже — что в порядке и что предлагаю поправить, по приоритетам.

---

## ✅ Что в порядке

- **OG / Twitter / JSON-LD** — даты 18–24 октября 2026, цена €1950, capacity 14, изображение `/og-image.jpg` отдаются корректно (HTTP 200, новый etag).
- **Canonical** `https://tennerife-tennis.com/` + `sitemap.xml` + `robots.txt` на месте.
- **Security headers** (HSTS, X-Content-Type-Options, Referrer-Policy) и кеширование статики настроены через `netlify.toml`.
- **SPA fallback** настроен и в `netlify.toml`, и в `public/_redirects`.
- **Доступность ресурсов:** `/`, `/og-image.jpg`, `/hero-bg.mp4` отвечают 200.
- **A11y базово:** `lang="ru"`, semantic `<main>/<section>/<nav>`, `aria-label` на иконках, фокусные кнопки.
- **Telegram-форма** работает через edge-функцию `send-booking`, RLS не нужен (нет таблиц).

## 🔴 Высокий приоритет

1. **Дубль секции «Формат»**
   В `src/pages/Index.tsx` две секции с эйбровом «Формат»: блок `#who` (строки 229–239) и блок `#fit` «Кому подойдёт» (строки 438–467). На лендинге одинаковый тег визуально повторяется → выглядит как недосмотр. Предлагаю изменить тег у одной из них (например, `#fit` → «Кому подойдёт» или «Подбор группы»).

2. **`og:image` MIME-type подозрительный**
   `curl -I /og-image.jpg` отдаёт `content-type: text/html; charset=utf-8` для одного из ответов, хотя сам файл — JPEG. Вероятно сработал SPA-fallback (`/* → /index.html`). Нужно проверить, реально ли файл лежит в `public/og-image.jpg` после деплоя. Если нет — соцсетям отдаётся HTML вместо картинки. Решение: явное правило в `netlify.toml`, исключающее статику из SPA-fallback, либо убедиться, что файл попадает в `dist/`.

3. **`hero-bg.mp4` без кеш-заголовка**
   Видео hero отдаётся без `Cache-Control: immutable`. Файл, скорее всего, тяжёлый — стоит добавить правило в `netlify.toml` для `*.mp4` (max-age=31536000).

## 🟡 Средний приоритет

4. **SEO-title слишком длинный (~75 символов)**
   `Tennerife Tennis Retreat — премиальный теннисный кемп на Тенерифе` обрезается в выдаче Google (>60). Предлагаю короче, например: «Tennerife Tennis Retreat — Тенерифе, 18–24 окт 2026» (≈55).

5. **Шрифты в `index.css` ≠ шрифтам в memory**
   В памяти проекта закреплено: Cormorant Garamond + Source Sans 3. В `src/index.css` подгружаются Playfair Display + Fira Sans. Либо обновить шрифты в коде, либо обновить memory — сейчас расхождение.

6. **Sitemap `lastmod=2026-05-04`** в будущем относительно сегодня (12 мая 2026 — ок, но если правки в индексе/страницах — обновить дату).

7. **Hero `<video>` без `aria-hidden` дубля для скринридеров уже стоит**, но стоит добавить `<track kind="captions">` либо `aria-hidden="true"` уже есть (строка 177 — ок). Проверить, что на iOS Low Power Mode видео не ломает layout (есть `poster="/hero-poster.jpg"` — хорошо).

8. **WhatsApp ссылка** теперь `api.whatsapp.com/send/?phone=89655096888` — работает, но формат `8…` нестандартный (международный должен быть `7…`). На десктопе WhatsApp Web может отказать. Рекомендую перепроверить вручную с десктопа и мобилы.

9. **`max.ru` иконка** — текущая SVG (строки 46–50) не похожа на официальный логотип MAX. Стоит использовать корректную иконку.
